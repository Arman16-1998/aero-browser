# Contributing to Aero

## The short version

- Bug fixes and docs: open a PR directly.
- New features: open an issue first, wait for a maintainer response.
- Be patient. This project is maintained around a school schedule.

## Maintainer availability

The maintainer is a student in Hyderabad, India. Expect:

- **Weekdays:** limited availability, mostly evenings IST
- **Weekends:** primary triage and merge window
- **Sept 28 – Oct 9, 2026:** full break for mid-term exams. No responses during this window.

If you don't hear back within a week, it's not personal. It's school.

## What we're looking for

See the lanes table in the [README](README.md). Each lane has a `help wanted` issue. Pick one, comment on it, and start.

## What we're not looking for

- Ads, in any form
- Cryptocurrency features
- Telemetry, "anonymous" or otherwise
- VPN integrations that monetize users
- AI features that send data to a server
- Anything that contradicts the README

## Code style

Match the surrounding code. Chromium has its own style guide; follow it. For docs, plain English, no marketing speak.

## PR process

1. Open the PR against `main`
2. Describe what it does and why
3. Link the issue it addresses
4. Wait for review. If you don't hear back in a week, ping the PR.

## Questions

Open an issue. Don't DM the maintainer.
