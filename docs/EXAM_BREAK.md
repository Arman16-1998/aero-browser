The maintainer is a 14-year-old student in Hyderabad. Mid-term exams are happening. Aero is paused during this window.

## What this means

- Issues and PRs will not be reviewed until **Oct 10, 2026**
- The project is not abandoned

Everything gets triaged in order. PRs first, then issues. Expect a slow first week back as the maintainer catches up on school.

## Why this is written down

So nobody thinks the project is dead. So contributors know what to expect. So future maintainers know this was planned, not a crisis.
